# Bookysol Web 🌷📚

Sitio web personal desarrollado como proyecto final del curso de **Desarrollo Web en Coderhouse**.

## 💡 Descripción
**BookySol** es un sitio dedicado a mis proyectos literarios, reseñas de libros y escritos personales.  
El objetivo del sitio es compartir mi trabajo como escritora y ofrecer un espacio estético y navegable que refleje mi estilo.

## 🧱 Estructura del sitio
El sitio cuenta con **5 secciones**, cada una en un archivo HTML distinto:
1. **Inicio** – Presentación general y enlaces a las demás secciones.
2. **Sobre mí** – Breve biografía y presentación personal.
3. **Reseñas** – Galería de algunas reseñas de libros con estructura en grid.
4. **Cenizas** – Página dedicada a mi poemario *Cenizas de anhelos inquebrantables*.
5. **Contacto** – Formulario para enviar mensajes y conectarse conmigo.

## 🛠️ Tecnologías utilizadas
- **HTML5** y **CSS3**
- **SASS** (con anidación, variables, mixins y partials)
- **Bootstrap 5**
- **Flexbox y Grid**
- **Media Queries** para diseño responsive
- **Animaciones CSS / Transiciones**
- **Buenas prácticas de SEO y accesibilidad**
